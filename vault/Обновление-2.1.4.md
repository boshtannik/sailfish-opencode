# Обновление вендоренного opencode 2.0.32 → 2.1.4

Рабочий чеклист. Статусы: `[x]` — сделано · `[~]` — в работе · `[ ]` — не начато.
Эталонная дельта снята 2026-10-27 (см. «Дельта» ниже), бинарь 2.1.4 уже скачан.

---

## Дельта API 2.0.32 → 2.1.4 (снята с живого `serve`)

Реестр событий: 154 → 155 имён.
- удалено: `session.compacted` (в 2.1.4 строки нет вообще);
- добавлено: `session.archived`, `session.unarchived`;
- `session.compaction.ended` остался — на нём висит UI компакции, ничего не теряем.

Пути: 119 → 124, удалённых нет. Добавлены только отладочно-экспериментальные:
`/api/debug/heap-dump`, `/api/experimental/client-mcp`, `/api/experimental/client-mcp/token`,
`/api/experimental/voice/models`, `/api/experimental/voice/session/{sessionID}/instructions`.
Изменённый существующий путь: `/api/permission/saved/{id}` (+`PATCH`).

Схемы: 293 → 293. Значимое для нас:
- `Session.Message.Compaction.Running` / `.Completed` — **убрано обязательное поле `recent`**
  (у `Completed` также `providerState`, `providerContext`; добавлено `native`);
- `Session.Message.Assistant` / `.Text` / `.Tool` / `.Reasoning` — `providerState` → `native`
  (мы их не парсили, unknown-поля игнорируются);
- `Session.StructuredError` — добавлено `retryAfterMs` (опционально);
- `Credential.Key` — убрано `configuration` (клиент `/api/credential` не использует);
- `Model.Compatibility` / `Provider.Compatibility` — добавлено `streamUsage` (не парсим);
- новые: `VoiceModel*`, `PermissionSavedNotFoundErrorEncoded`, `Session.Message.Native*`.

Тела запросов используемых эндпоинтов не менялись. Рукопожатие `serve`
(`server listening on …` / `server password …`) идентично.
